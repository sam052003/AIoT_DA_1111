# 05｜擴充後開發路線圖與任務清單

> 基準：原始提案以 W1–W6 規劃「測站尺度短期預測＋Agent」；2026-11-24 決策將後續 500 字摘要的**個人／累積暴露、路線級導航、SHAP、替代時段**也納入**最終必做功能**。以下 W7–W10 是新增的**建議工作週**，非已確定的截止日期；依課程實際期限排程與分工。

## 00｜優先級不是選做

| 階段 | 研究功能 | 需求範圍 | Gate |
|---|---|---|---|
| **M1 測站級核心（必做）** | 官方空品、1／3／6h PM₂.₅、Agent、官方規則、安全降級、回測 | FR-01～04、10～12 | G1：資料可信＋雙軌基本測試 |
| **M2 個人決策（必做）** | SHAP、活動與替代時段、累積暴露／自訂預算 | FR-05～07 | G2：可核算暴露＋清楚單位與假設 |
| **M3 路線導航（必做）** | OD 候選路線、路段濃度時空推估、估計暴露／熱點、時間成本權衡 | FR-08～09 | G3：路段資料證據＋獨立驗證；未通過不可聲稱可靠低暴露導航 |

## 02｜依賴關係（先後順序）

```text
官方資料 + Quality + station/time contract
   ├─→ 短期 PM₂.₅ ＋ rolling-origin → uncertainty ──┐
   ├─→ 官方 AQI 活動規則 ───────────────────────────┤
   ├─→ Web + Agent Tool Allowlist ──────────────────┤→ 活動決策／時段比較
   └─→ 氣象／地理、資料來源與時間窗 ────────────────┘
                                       │
                  時段濃度估算 + 活動時長 + 假設 → 累積暴露
                                       │
               路網 + 交通時距 + 路段時空污染模型 → 路線比較
                                       │
                    獨立路段證據 + 可信度檢核 → 有條件的低暴露建議
```

## 03｜工作包與子任務

### WP-A｜Data（W1–W2）
- [ ] 測站清單、AQX_P_432／AQX_P_488／AQX_P_13 API／CSV 版本確認。
- [ ] 時戳＋時區＋平均窗＋單位＋品質欄位標準化。
- [ ] 記錄觀測時間與發布時間；不可使用預測時點後才知道的資料。
- [ ] 覆蓋率、缺失率、延遲率、可重現資料抽取。

### WP-B｜ML／XAI（W2–W7）
- [ ] 三個預測時距＋兩個 Baseline。
- [ ] Ridge／Random Forest／XGBoost，同資料與切分比較。
- [ ] MAE／RMSE／Skill、測站／事件分層與 uncertainty；如實呈現負結果。
- [ ] 適配模型的 SHAP，提供局部與整體特徵貢獻、非因果說明。

### WP-C｜Agent／Domain（W3–W5）
- [ ] 情境解析：地點、起終點、時段、交通方式、活動強度、敏感性。
- [ ] Tool Allowlist、數值守門、AQI 分流、官方規則版本。
- [ ] 30+ 固定情境、來源追溯、工具正確率、規則一致率、降級測試。
- [ ] API 延遲／工具錯誤／站點歧義／時距越界安全處理。

### WP-D｜Personal Decision（W4、W7）
- [ ] 時段候選比較、官方指引與不確定性。
- [ ] 分段暴露 `Σ(C × Δt)`，覆蓋率與估算方法可見。
- [ ] 每日累積與自訂比較門檻；避免宣稱醫療上的安全日額度。
- [ ] SHAP 轉成一般使用者可理解的「預測參考因素」。

### WP-E｜Route（W8–W9）
- [ ] 起終點路線生成及交通方式，至少兩條候選路線。
- [ ] 路段幾何、路段行進時間、交通環境、空間污染推估資料盤點。
- [ ] 路段／時間污染估算＋不確定性＋`Σ(C_i Δt_i)`。
- [ ] 與最快路線比較時長／暴露取捨，展示風險熱點及替代出發時段。
- [ ] 以獨立資料驗證**路線排序**；未通過時顯示「無可靠路段污染比較」，絕不排名。

### WP-F｜Quality／Handover（全程＋W10）
- [ ] 模型及規則版本、資料契約、測試紀錄、API 文件。
- [ ] 系統截圖、真實 Demo、README、DESIGN、資料來源及部署指南。
- [ ] 文獻 DOI 與官方數據核查；明確區分 Proposal／期望／實測。
- [ ] Track A（ML）、Track B（Agent）、Track C（Exposure／Route）的可重現評估報告。

## 04｜驗收清單（完工前逐項勾選）

- [ ] G1：官方 AQI 資料／1、3、6h 預測／Agent 工具／規則／失效路徑通過。
- [ ] G2：SHAP 解釋、替代時段、暴露分段積分與累積結果可重算，含未知狀態。
- [ ] G3：有獨立路線級時空資料、路段污染排序驗證與明確不確定性；否則**標示尚未通過**。
- [ ] G4：≥30 Agent 案例與 ML／路線／暴露評估全部有報告與失敗案例。
- [ ] G5：README、DESIGN、原始提案、更新後需求、Demo 與實驗流程一致。
