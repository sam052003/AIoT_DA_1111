## 01｜研究定位

**Domain AI Agent × Domain Knowledge × Data Analytics × Real-World Application**

研究從「顯示空品」進一步走向「活動決策支援」，目標流程為：

```text
環境部監測／預報 + 氣象／時間／地理資料
    ↓ 時序對齊、資料品質檢查、來源記錄
1／3／6 小時 PM2.5 預測 + 不確定性
    ↓ 將官方 AQI 與模型預測分開標示
官方領域規則 + 使用者活動情境 + 受約束 Agent
    ↓
風險解釋／替代時段建議／缺值時安全降級
    └─ 進階：候選路線比較、個人暴露估計
```

## 02｜功能優先級

- **P0｜研究可驗證核心**：官方資料介接、資料品質、無時序洩漏回測、官方規則、Agent 工具白名單、雙軌評估。
- **P1｜情境決策功能**：活動時間與強度、敏感族群提醒、暴露估計、SHAP 解釋及建議理由。
- **P2｜路線級導航擴充**：引入道路交通與足夠時空解析度的污染資料，估計路段暴露，評估候選路線；完成資料與方法驗證前，**不可宣稱具有可靠的街道級路線推薦能力**。

## 03｜科學與安全邊界

1. 單一污染物 PM2.5 預測**不等於**官方未來 AQI。
2. 測站資料不代表道路、街角或個人實際吸入劑量；「較低暴露路線」需要額外資料與驗證。
3. 文獻所述降幅是**其他研究的情境結果**，不是 AirGuard AI 的實測效果。
4. AI Agent 不得捏造數值、來源、監測時間或醫療診斷；資訊不可靠時應明示不確定性並安全降級。
5. 正式研究報告應補齊文獻題名、作者、年份、DOI／網址及主張對應出處，見 [03](./03_引用證據與待核查事項.md)。

## 04｜交付與驗收方向

- 可重現的資料前處理、模型訓練和 **1／3／6 小時** 回測。
- Persistence／Seasonal Naive 與 Ridge／Random Forest／XGBoost 的可比結果：**MAE、RMSE、Skill Score**。
- **至少 30 個**固定 Agent 情境案例：工具選擇、證據來源、規則一致與安全降級。
- 使用情境、系統架構、限制聲明與實驗結果；未完成者明示「規劃中」。
