## 01｜研究與系統定位

**Domain AI Agent × Domain Knowledge × Data Analytics × Real-World Application**

```text
環境部官方監測／預報 + 氣象／時間／地理 + 路網與路段證據
   ↓ 資料時效、時空尺度、單位與發布時間檢核
測站級 1／3／6h PM₂.₅ 估計 + 不確定性 + SHAP
   ↓ 官方 AQI 活動指引 + Agent 受控工具
活動時段比較 + 活動強度與累積暴露估算
   ↓ 具足夠路段時空證據與獨立驗證時
候選路線估計暴露比較 + 熱點 + 替代路線／時段
   ↓
有來源的行動建議；資料不足則明示未知與安全降級
```

## 02｜最終範圍：三階段，全部必做

| 階段 | 必做範圍 | 交付 Gate |
|---|---|---|
| **M1 測站級核心** | 官方 AQI／歷史、PM₂.₅ 預測、受控 Agent、活動規則、Web、來源與安全降級 | G1：Track A／Track B 有可信結果 |
| **M2 個人決策** | SHAP、活動與替代時段、時長／強度、分段與每日累積暴露、自訂預算 | G2：單位／方法／資料完整性可核算 |
| **M3 路線導航** | OD／交通方式／出發時間、候選路線、路段時空污染、熱點、暴露與時間取捨 | G3：**經獨立資料驗證後**才提供可靠路線污染排名 |

**P0/P1/P2** 僅表示過去草案的開發先後，**不表示 P1/P2 是選做**。新版採 M1～M3 明確標示「必做」。

## 03｜功能驗收與科學邊界

- 必做功能及驗收條件完整記錄在 [04 SRS](./04_系統功能需求與驗收標準.md)。
- **Track A**：Persistence／Seasonal Naive、Ridge／Random Forest／XGBoost，1／3／6h，70／15／15 時序切分＋Rolling-origin，MAE／RMSE／Skill。
- **Track B**：≥30 Agent 固定案例，工具選擇、來源完整、規則一致、安全降級與延遲。
- **Track C**：累積暴露計算可重算，路段時空資料覆蓋、路線污染排序與獨立驗證。
- **官方 AQI 不等於模型 PM₂.₅**；**測站資料不等於街道污染真值**；**濃度×時間不是個人實際吸入量**；SHAP 不是因果證明。
- M3 遇缺乏可信路段資料時，**必須呈現不可用並說明限制**，同時紀錄功能未達驗收，不能用無證據的排行榜代替。
- 文獻引用降幅不是 AirGuard AI 已達成的減暴露效果。
