# 04｜系統功能需求與驗收標準（SRS v2）

> 狀態：**新版實作需求規格**；以原始提案及後續約 500 字研究摘要為依據，2026-11-24 確認擴充範圍。**本文件描述必做目標，不表示已完成。**
>
> **重要決策**：路線級空品決策導航、個人／累積暴露管理、SHAP 可解釋性與替代時段建議，全部由「進階／選做」升級為**期末系統必做範圍**，但允許依資料與驗證門檻分階段開發。不可因缺乏路段證據而捏造低暴露路線。

## 00｜範圍與原則

- **必要功能 ≠ 同時開發**：M1 測站級核心 → M2 個人決策 → M3 路線級驗證；M1–M3 均屬最終交付範圍。
- **科學邊界**：官方發布 AQI 與模型預測 PM₂.₅ 分流；測站級預測不能直接當路段真值；暴露指標不等於實際吸入劑量或醫療診斷。
- **證據邊界**：外部研究的暴露降低百分比僅為文獻結果，不是 AirGuard AI 的承諾或實測成效；參考 [引用證據清單](./03_引用證據與待核查事項.md)。
- **完成定義**：可操作 Demo＋可追溯資料＋測試＋研究限制＋可重現實驗記錄。驗收前不得標為 Done。

## 02｜使用者情境與預期行為

| 情境 | 輸入範例 | 系統應做 | 不可做 |
|---|---|---|---|
| S01 運動規劃 | 「今天傍晚在臺中慢跑 40 分鐘可以嗎？」 | 找測站、官方 AQI、可用預測、規則與替代時段 | 不憑空說某時段一定安全 |
| S02 敏感族群 | 「我較敏感，戶外快走 30 分鐘？」 | 官方活動指引優先、提醒限制與適用性 | 不進行個人診斷 |
| S03 累積暴露 | 「我今天已在戶外 2 小時，還想騎車 1 小時」 | 累加有資料時段的估算暴露，揭露區域與假設 | 不把濃度×時間說成吸入劑量 |
| S04 路線比較 | 「A 到 B，步行，16:00 出發，哪條污染較低？」 | 取得多條可行路線，若有路段污染模型則比較估計暴露與行程成本 | 不用測站單點值直接宣稱某街道更乾淨 |
| S05 無路段資料 | 「A 到 B 走哪條空氣最好？」 | 顯示候選路線／交通資訊，明確標示空污比較不可用並提供一般建議 | 不產生無證據的暴露排名 |
| S06 時距越界 | 「明天早上 7 點的 PM₂.₅ 精確值？」 | 1／3／6h 不涵蓋時不套模型；可引用有時效的官方預報並明示性質 | 不把官方區域預報或模型猜測冒充逐時實測 |
| S07 服務異常 | 「AQI API 失效怎麼辦？」 | 顯示資料過期與最近可靠資訊／官方來源 | 不輸出假即時 AQI |

## 03｜預測模組驗收（Track A）

1. 官方即時／歷史資料需完成時區、資料發布時間、測站、單位、平均窗及缺值檢核；來源：AQX_P_432、AQX_P_488、AQX_P_13（實作前核對版本與欄位）。
2. **測站尺度**的 1／3／6h PM₂.₅；Persistence、Seasonal Naive 為基線，Ridge、Random Forest、XGBoost 為候選模型。
3. 使用原提案規劃 **70／15／15 chronological split ＋ rolling-origin**；test 不參與調參；只使用預測發出時真正可取得的歷史／氣象資料。
4. 分測站、時距、季節與高污染事件報告 MAE／RMSE／Skill Score、樣本數與誤差或區間；模型未勝基線也如實呈現。
5. SHAP 解釋只做**模型特徵貢獻**，不能宣稱污染機制因果已獲證實。

## 04｜個人暴露與決策驗收（Track B／C）

### 04.1 暴露計算

- 最低可重現指標：`ExposureIndex = Σ(concentration_μg_m3 × duration_hours)`，單位 **μg·h/m³**；這是**濃度–時間積分**，不是呼吸攝入量、個人實測暴露或醫療健康指標。
- 以每段活動的路段或測站尺度濃度估算，記錄來源／時間窗／活動類別／估算方法；資料不足時不填零，應回傳 unknown 與覆蓋率。
- 「活動強度」先作決策維度與假設標示；若使用通氣量推估 inhaled dose，需另有來源與模型驗證，不能混用單位。
- 「暴露預算」是**使用者自訂的比較門檻**，不能宣稱存在通用安全日額度；輸出累積值、比較值、限制與替代方案。

### 04.2 路線級導航上線門檻

- 必須取得**至少 2 條實際可行的路徑**及路段時距資訊；路網資料、地理座標、行程時間、污染時空推估、空間覆蓋率均須明確。
- 定義路段估算 `C(segment, time)` 與路段行經時長，計算 `RouteExposure = Σ(C_i × Δt_i)`；對同一 OD／出發時間／交通方式比較。
- **必要獨立驗證**：以移動量測、路旁站或獨立可比較資料評估路線排序有效性；至少報告觀測數、覆蓋率、誤差、不確定性與局限。
- 若路段資料不可用或未通過驗證，系統仍需提供**可運作的路線頁面與明確不可用狀態**，不得生成低污染路線排名或假熱點；此狀態不能算路線污染模型已通過驗收。
- 比較最短時間、估計最低暴露及改時出發三種方案；建立透明的決策權衡，不對健康減害提供數字保證。

### 04.3 Agent／系統可靠性

- ≥30 個固定情境，覆蓋正常活動、敏感族群、同名站點、缺值／延遲、超時距、官方 AQI／預測混淆、路線資料不足與暴露估計。
- 指標：工具選擇正確率、來源完整率、官方規則一致率、安全降級成功率、P50／P95 延遲。
- 選擇性深入研究（**不是必要功能的替代品**）：在取得原始文獻定義後，納入 Mean Excess Exposure（MEE）或等價的決策損失指標，以比較策略造成的額外估算暴露。

## 05｜非功能需求及阻斷條件

| ID | 要求 | 交付證據 |
|---|---|---|
| NFR-01 | 使用者可辨別「官方 AQI／模型 PM₂.₅／預估暴露」三種資訊 | UI 標籤、API schema 與測試 |
| NFR-02 | 所有數值有來源、觀測／取得時間、單位、位置及計算方式 | 完整資料契約、記錄與審計 |
| NFR-03 | 失效或無法驗證時安全降級，不能生成虛假路段污染圖 | Failure case 測試 |
| NFR-04 | 模型及特徵、案例測試、規則版本、資料期間可重現 | scripts、lockfile、固定 seed、評估報告 |
| NFR-05 | 禁止個人診斷、無證據因果宣稱及文獻效果冒充本系統成果 | 內容測試、限制聲明 |

**阻斷條件（release gate）**：未完成的路線污染驗證不得宣稱「可靠降低暴露」；未有實測個人監測資料不得宣稱「真實個人吸入量」；不完整的時間／單位／來源不得顯示成確定數值。
